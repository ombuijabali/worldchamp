# WorldChamp Phase 5.1 - Static Participation Test

Phase 5.1 keeps the locked Phase 4.1 location engine and Phase 5 participation gate, but removes the need for 5-minute Bar Replay during validation.

## Added for free-plan testing

- Historical participation markers on every 5-minute bar inside the configured New York active window.
- Marker legend: `H` = high, `N` = normal, `L` = low, `W` = baseline warming, `X` = no volume.
- A compact end-of-session summary such as `P H3 N9 L6 W0 X0`.
- The live/current dashboard participation row is unchanged.

No trade execution or order-flow entry logic is added.
