# WorldChamp

TradingView decision-support indicator inspired by the Chris Creamer order-flow workflow.

## Goal

Build and validate the system in phases from 4H context down to 5M confirmation while keeping trade execution manual.

## Core principles

- Pine Script v6
- Primary operating chart: 5 minutes
- Context timeframes: 4H, 1H, 15M
- Confirmed/non-repainting HTF data for decision logic
- New York session-aware behavior
- Seven-day validation before broad historical testing
- Clean, minimal drawings and dashboard-first status reporting
- No automated entries, exits, or broker execution
