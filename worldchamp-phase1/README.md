# WorldChamp - Phase 1

Phase 1 extends the Phase 0 TradingView foundation with a confirmed higher-timeframe environment engine.

## Added in this phase

- Confirmed 4H swing structure.
- Confirmed 1H swing structure.
- UP / DOWN / BALANCED / WARMING states.
- 4H + 1H alignment and pullback states.
- Latest structural swing levels only (no historical line clutter).
- Cleaner status line: inputs and debug plots are hidden from the normal TradingView header.

## Not built yet

- Actual value-area / POC migration.
- GEX.
- Fibonacci/location engine.
- Participation filter.
- Footprint/order-flow confirmation.
- Entry or execution automation.

Read `docs/phase1-testing.md` before promoting this phase.
