# WorldChamp Phase 1.2

Phase 1.2 refines the higher-timeframe structure vocabulary without adding trade-entry logic.

## Structure states

- `TREND UP`: HH + HL
- `TREND DOWN`: LH + LL
- `CONTRACTING`: LH + HL
- `EXPANDING`: HH + LL
- `NEUTRAL`: equal/ambiguous swing relationships
- `WARMING`: insufficient confirmed pivots

The combined 4H/1H state distinguishes alignment, pullbacks, compression, transition, and mixed structure.
